# Настройка нового сервера 5.182.87.217

Чистая установка: база начинается пустой, со старого сервера ничего не переносится. Займёт около 15 минут.

## 1. Ключ для автообновления

На своём компьютере (Windows, PowerShell):

```powershell
ssh-keygen -t ed25519 -f $HOME\.ssh\zapchasti_deploy -N '""'
```

Получится два файла в папке `C:\Users\<вы>\.ssh\`:
- `zapchasti_deploy.pub` — **открытый** ключ, его вставляете в скрипт на сервере (шаг 2);
- `zapchasti_deploy` — **закрытый** ключ, его вставляете только в секрет `DEPLOY_KEY` на GitHub (шаг 3). Больше никуда, в чат тоже.

## 2. Настройка сервера

Зайдите на сервер под root (`ssh root@5.182.87.217`) и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/RoulinFeed/zapchasti-qr/main/deploy/setup-server.sh -o setup.sh
bash setup.sh
```

Скрипт:
1. включит подкачку 2 ГБ (без неё 1 ГБ памяти мало для базы и приложения);
2. поставит Docker;
3. создаст пользователя `deploy` и попросит **открытый** ключ из шага 1;
4. создаст папку `/home/deploy/zapchasti-qr`;
5. спросит домен, логин и PIN администратора и создаст `.env`. Пароль базы он придумает сам, он хранится только на сервере;
6. запустит пустую базу. Само приложение привезёт GitHub на шаге 5.

Скрипт можно запускать повторно: что уже сделано, он пропустит.

## 3. Секреты на GitHub

GitHub → репозиторий `zapchasti-qr` → Settings → Secrets and variables → Actions. Поменять (карандаш у каждого секрета):

| Секрет | Новое значение |
|---|---|
| `DEPLOY_HOST` | `5.182.87.217` |
| `DEPLOY_USER` | `deploy` |
| `DEPLOY_PATH` | `/home/deploy/zapchasti-qr` |
| `DEPLOY_KEY` | всё содержимое файла `zapchasti_deploy` (без `.pub`), включая строки `-----BEGIN…` и `-----END…` |

## 4. Адрес сайта

- **Есть свой домен:** у регистратора поменяйте A-запись на `5.182.87.217` и на шаге 2 укажите этот домен.
- **Своего домена нет:** оставьте предложенный `5-182-87-217.sslip.io`, настраивать ничего не нужно.

HTTPS сертификат сервер получит сам при первом запуске. Если адрес отличается от прежнего, приложение на телефонах нужно установить заново с нового адреса.

## 5. Запуск

GitHub → Actions → deploy → **Run workflow**. Через 2–3 минуты шаг «Проверить, что приложение отвечает» должен стать зелёным. Дальше каждое обновление в `main` будет приезжать само.

Откройте сайт и войдите логином и PIN из шага 2.
